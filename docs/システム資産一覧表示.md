# システム資産管理

### 全体設計（完成形）

```text
ポータル
  ↓
一覧リクエスト（検索条件入力）
  ↓
チケット
  ↓
Automation
  ↓
結果をコメントで一覧表示
```

---

### ③ Automation設計（コア）

#### ■ トリガー

👉 Issue Created

#### ■ 処理の流れ
```text
① 入力値取得
② AQL生成
③ Assets検索
④ 結果整形
⑤ コメント出力
⑥ チケットクローズ
```

---

### ④ AQL生成ロジック
入力に応じて動的に変える

#### ■ ベース
必要なオブジェクトを選択する
```aql
objectType = "Subsystems"
```

#### ■ 条件追加

##### 状態
```aql
AND 稼働条件 != "非稼働"
```

##### システム
```aql
AND システム = "{{issue.システム}}"
```

👉 Automationのスマート値で組む

---

### ⑤ Automation実装イメージ

#### ■ アクション
👉 「Lookup Objects」

#### ■ AQL
```aql
objectType = "Subsystems"
AND 稼働区分 != "非稼働"
{{#if(issue.システム)}}
AND システム = "{{issue.システム.name}}"
{{/}}
{{#if(issue.利用者)}}
AND 利用者 = "{{issue.利用者.accountId}}"
{{/}}
```

#### ■ 結果取得

👉 `{{lookupObjects}}`
